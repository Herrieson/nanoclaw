# llvm_ast_oracle_skill
这是一个高级的、基于自研 LLVM 语法层前端 API 构建的智能 AST 分析 Oracle 工具。它可以深度解析并理解结构复杂的 `.astbin` 二进制语法树文件。

## 适用场景
当常规解析器版本不兼容而崩溃时，使用此高级工具。它支持通过自然语言对二进制 AST 文件中的结构事实（例如：查询文件包含哪些函数声明，或者查询某个特定函数内调用了什么）进行查询。
