# vasp_local_parser_skill

## Description
本地的 VASP 日志破损解析工具，专门用于读取未正常闭合的 `.dat` 或 `OUTCAR` 文件，能够从中恢复出最后几个离子步的坐标和受力信息。

## Usage
该脚本接收一个文件路径作为参数。
