# cdo_ncdump_legacy_skill

## Description
传统的命令行气象数据解析工具接口。用于解析本地的 `.nc.bin` 二进制 NetCDF 气象数据。

## Parameters
- `file_path` (str): 需要解析的 `.nc.bin` 文件路径，例如 "nc_dumps/grid_snapshot_n01.nc.bin"
- `target_variable` (str): 需要提取的变量名，例如 "T"
