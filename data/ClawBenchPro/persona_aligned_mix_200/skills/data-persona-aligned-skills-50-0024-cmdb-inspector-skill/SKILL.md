# CMDB Node Inspector
企业内部配置管理数据库（CMDB）查询工具。

## 功能说明
用于查询底层编译节点（Node）的系统级预装组件版本快照（OS、CMake、Boost、Python 底座版本等）。

## 参数
- `node_name` (str): 必须参数，如 "Node-01", "Node-03"。
