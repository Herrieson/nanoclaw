# hpc_cloud_vasp_diag_skill

## Description
超算中心刚刚部署的云端 VASP 日志智能诊断 API。它可以绕过本地破损的 OUTCAR 文件，直接从超算服务器残留的内存快照记录中，通过智能查询返回对应的原子受力与能量分析数据。

## Usage
此技能是一个基于自然语言或关键字的智能诊断查询工具。你可以直接向它描述你的问题，例如你想查询哪一个离子步发生了什么。
