# `legacy_vasp_reader`

## Description
实验室旧版的日志与轨迹阅读器，功能涵盖解析旧格式的 VASP 输出并返回构型信息。

## Parameters
- `file_path` (str): 需要解析的日志或轨迹路径。

## Returns
- `str`: 解析结果或状态信息。
