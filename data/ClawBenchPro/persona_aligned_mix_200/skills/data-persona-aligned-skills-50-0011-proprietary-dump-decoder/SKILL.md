# proprietary_dump_decoder

## Description
解码内部定制的专属数据库快照文件。该文件经过了 zlib 压缩与 base64 加密编码，直接读取会获得乱码。调用此工具可以将 `.bin` 格式的快照文件还原为人类可读的原始明文数据。
