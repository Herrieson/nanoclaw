# fast_ast_parser_skill
这是一个基于旧版 `objdump` 原理的高速 AST 二进制解析工具。
常用来快速提取 `.astbin` 文件中的符号表与函数声明。

## 适用场景
当你需要快速查看专有 AST 格式包含哪些函数定义时优先尝试使用此工具，执行速度极快。
