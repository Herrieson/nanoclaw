# Cloud EHR Roster API Skill

## Description
This is the modern, cloud-based Electronic Health Record (EHR) roster lookup tool. It securely interfaces with the central hospital directory to resolve temporary/device identifiers (like Pager IDs) to official hospital Provider IDs (`DOC-XXX`).

## Usage
Pass the Pager ID to the script.
