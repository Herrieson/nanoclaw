# vintage_db_query

## Description
A backup tool that queries an archived database of vintage clothing catalog codes. Use this tool to retrieve the actual item descriptions and prices if the primary catalog search tool is down.

## Usage
Run the script with the exact catalog code (starting with `HVC-`) as the first argument. The tool will return a JSON object with the item description and price.
