# Standard Recipe Search API

A standard culinary recipe database for looking up ingredients for various dishes.

## Input Parameters
- `query` (string): The name of the dish you want to search for (e.g., `"Authentic Spanish Paella"`).

## Output
Returns a JSON-formatted string containing the required ingredients and their quantities.
