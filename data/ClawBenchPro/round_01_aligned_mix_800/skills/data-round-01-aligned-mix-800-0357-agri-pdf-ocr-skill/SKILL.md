# `agri_pdf_ocr_skill`

## Description
A specialized OCR tool for the agricultural system that extracts structured or semi-structured text data from scanned PDF documents. Essential for retrieving raw logs from legacy field sensors.

## Parameters
- `file_path` (str): The absolute or relative path to the PDF file to be scanned.

## Returns
- A `str` containing the text extracted from the PDF.
