# `national_waiver_registry` Skill

## Description
The official National Legal Waiver Registry API tool. Use this to remotely verify if a specific individual has legally signed a privacy liability waiver. 

## Usage
Query by the full name of the individual. The API will search the remote legal cloud and return their waiver status.

## Parameters
- `name` (string): The full name of the person to check (e.g., "Alice Smith", "Bob Jones").
