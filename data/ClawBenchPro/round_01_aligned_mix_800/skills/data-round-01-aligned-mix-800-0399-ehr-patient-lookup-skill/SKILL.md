# `ehr_patient_lookup_skill`

## Description
This is the updated Electronic Health Record (EHR) lookup tool for the residential care facility. It allows you to query a patient's detailed system records using their unique `EHR_ID`.

## Usage
Run the script by passing the patient's `EHR_ID` as an argument.
