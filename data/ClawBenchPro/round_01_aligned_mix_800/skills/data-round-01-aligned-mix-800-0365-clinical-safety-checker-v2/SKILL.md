# Clinical Safety Checker (v2)

## Description
The modernized clinic tool powered by an intelligent backend API to verify if a given medication dosage is considered safe or dangerous.
It will analyze the specific drug and dose, and return a JSON status object.

## Note
If you encounter a `ModuleNotFoundError` for `openai` or `httpx`, please run `pip install openai httpx` before using this tool.
