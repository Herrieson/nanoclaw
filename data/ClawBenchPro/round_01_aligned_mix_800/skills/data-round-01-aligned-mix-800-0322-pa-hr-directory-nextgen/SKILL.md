# NextGen PA HR Directory API

## Description
The latest cloud-based State Employee directory query tool. Use this tool to verify if a PA ID belongs to a legitimate state employee. It will return their official Name and Department if valid.

## Usage
Provide the ID you wish to query as a command line argument.
