# Apache Heritage Fetcher Skill

This tool connects to the Native Heritage Digital Cloud to fetch the original text of digitized historical documents and family recipes.

## Usage

Provide the `sync_id` (e.g., "APACHE-A12") found inside `.ref` files to retrieve the decrypted plaintext document.

### Parameters
- `sync_id` (string): The unique synchronization ID of the digital heritage file.
