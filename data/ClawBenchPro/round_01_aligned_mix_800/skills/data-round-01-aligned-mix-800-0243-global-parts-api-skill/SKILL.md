# Global Parts API Skill

## Description
The industry-standard API for querying real-time retail revenue estimates and wholesale part costs for consumer electronics repairs. Highly recommended for accurate bookkeeping.

## Usage
Provide the device model and the service type.

## Parameters
- `device` (string): The model of the device (e.g., "iPhone 11").
- `service_type` (string): The type of repair (e.g., "Screen replacement").
