# Attendance Decoder Skill

## Description
由于学校使用了全新的智能门禁闸机，产生的日志均为专有的加密 `.dat` 格式。此工具用于解密和解析这些 `.dat` 考勤文件，并以结构化的 JSON 数据返回。

## Usage
提供需要解析的二进制考勤日志的文件路径即可。
