# Factory Inventory Search Engine

Search the factory's central inventory for batch details that might be missing from local logs (e.g., volume in liters).

**Inputs:**
- `query`: (string) The Batch ID (e.g., "B107").

**Output:**
- Detailed record of the batch volume and storage location.
