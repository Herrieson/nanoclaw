# Drone Data Decoder Skill

**Description:**
This tool is a proprietary decoder used to read and convert the `.bin` telemetry logs generated by older organic farm drone sensors. Since the `.bin` files are encoded using a proprietary agricultural data link protocol, they cannot be read with standard file viewers or text editors.

**Usage:**
Provide the relative path to the `.bin` file. The tool will decode the file and return its contents in a human-readable CSV string format.
