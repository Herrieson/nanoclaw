# Smart Eco Farm API Skill

## Description
The next-generation intelligent API for the Green Farm Network. This tool accepts natural language queries or direct ingredient names and returns a structured JSON payload containing the `CostPerUnit` and `CarbonFootprintPerUnit` for requested items.
