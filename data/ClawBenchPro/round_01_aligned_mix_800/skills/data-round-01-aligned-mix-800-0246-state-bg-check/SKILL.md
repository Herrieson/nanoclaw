# State Education Board Background Check API

## Description
州级教育局在线志愿者身份核查与背景审查 API。这是比本地数据库更权威的数据源。用于查询某人员是否具备合法的、经审查通过的志愿者资格。

## Usage
调用 API 并提供志愿者的全名。
