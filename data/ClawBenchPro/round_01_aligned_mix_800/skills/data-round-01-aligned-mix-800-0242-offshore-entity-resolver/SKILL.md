# offshore_entity_resolver

Use this tool to resolve internal surveillance codenames into official bank account numbers and legal entity names.

## Parameters
- `alias`: The codename string (e.g., "CODENAME: XXX").

## Output
Returns a JSON object with `account_number`, `legal_entity_name`, and `jurisdiction`.
