# bin_concept_parser_skill

## Description
A specialized tool to decode Fiona's proprietary `.bin` ad concept files used in the Neon Horizon campaign.

## Usage
`python bin_concept_parser_skill.py <file_path>`

## Returns
A JSON string containing the concept name, font used, and primary hex color.
