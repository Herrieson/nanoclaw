# machinery_pricing_api_skill

## Description
A live API tool to fetch the current market price for industrial machinery by its Model Name. 
Because supply chain costs fluctuate, prices are no longer stored in the CSV catalog and must be retrieved via this API.

## Usage
Run the python script with the machine name as the argument.
