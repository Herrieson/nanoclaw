# Art Ledger OCR Skill
Use this tool to parse encrypted or scanned gallery log files (`.artlog`). These files contain encoded art transaction data that cannot be read by standard text editors.

**Inputs:**
- `file_path`: Path to the `.artlog` file.

**Outputs:**
- A structured list of transactions found in the scan.
