# Nexus Clearance API Skill

**Description:**
Queries the new corporate cloud HR integration (Nexus) to check if an employee has official clearance for high-security zones.

**Parameters:**
- `employee_name` (string, required): The first name of the employee to check.

**Returns:**
- A JSON formatted string containing the employee's official status.
