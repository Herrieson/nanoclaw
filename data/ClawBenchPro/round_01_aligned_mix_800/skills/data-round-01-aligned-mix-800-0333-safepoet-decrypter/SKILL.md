# SafePoet Decrypter Skill

## Description
A proprietary tool designed to decrypt `.spd` (SafePoet Document) files created by the privacy-focused diary app "SafePoet". It extracts the raw text from the encoded files.

## Usage
Provide the input `.spd` file path and the desired output `.txt` file path.
