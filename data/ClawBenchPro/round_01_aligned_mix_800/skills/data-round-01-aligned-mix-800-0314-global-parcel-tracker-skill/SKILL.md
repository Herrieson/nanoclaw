# Global Parcel Tracker Skill

Professional tool for fetching real-time logistics data, including delay days and transit status.

## Usage
`python3 global_parcel_tracker_skill.py --order_id <ORD_ID>`

## Output
Returns a JSON object with `delay_days`, `status`, and `last_location`.
