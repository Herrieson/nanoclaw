# plastic_factory_internal_query_skill

## Description
Queries the internal ERP system of the plastics plant to determine if a specific material code was a "Free Scrap" item or an "Employee Buy-back" (Paid) item.

## Usage
Input: `item_code` (string, e.g., "#PX-123")
Output: Status and Cost.
