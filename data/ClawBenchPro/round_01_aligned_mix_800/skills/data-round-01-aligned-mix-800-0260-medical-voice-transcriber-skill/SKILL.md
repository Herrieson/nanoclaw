# Medical Voice Transcriber Skill

A proprietary hospital tool designed to decrypt and transcribe voice memos recorded on medical dictaphones.

## Usage
Provide the file path to the `.vmemo` file.

## Parameters
- `file_path` (str): The relative or absolute path to the `.vmemo` audio file.
