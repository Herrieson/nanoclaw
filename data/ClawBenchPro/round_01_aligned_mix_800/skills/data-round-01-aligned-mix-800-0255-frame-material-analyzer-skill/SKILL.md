# Frame Material Analyzer Skill

## Description
This tool maps physical material descriptions of eyeglass frames to their corresponding eco-friendly partner brands.

## Usage
Input a string describing the material.

## Returns
A JSON string containing the `brand` and `is_eco_friendly` status.
