# `legacy_unpacker_skill`

## Description
An older version of the asset unpacker tool. Useful for extracting game assets packaged in version V1.0 to V2.1. It accepts the file path and attempts to parse it into readable JSON format. 

## Usage
Provide the relative or absolute file path to the packed asset file.
