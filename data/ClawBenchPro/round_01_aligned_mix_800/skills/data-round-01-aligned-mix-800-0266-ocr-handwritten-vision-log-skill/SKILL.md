# OCR Handwritten Vision Log Skill

## Description
This skill uses a specialized vision-language model to extract attendee names and observations from handwritten PDF scans specifically from vision screening events.

## Parameters
- `file_path`: (required) String. The path to the .pdf or image file.

## Usage
Call this skill to convert unreadable scanned logs into structured text.
