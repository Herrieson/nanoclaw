# GastroHub V1 Legacy API (REST)

This is the older version of the GastroHub API. It is considered deprecated by the provider but is still functioning for legacy accounts. It allows you to query shift hours flexibly by department and week.

## Usage
You must provide the department (e.g., `BOH` or `FOH`) and the week string (e.g., `2023-W42`) via command line arguments.
