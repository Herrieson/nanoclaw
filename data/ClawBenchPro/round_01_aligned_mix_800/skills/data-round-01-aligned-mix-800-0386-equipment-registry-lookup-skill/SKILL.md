# equipment_registry_lookup_skill

Look up asset IDs in the Community Repair Equipment Registry.

## Parameters
- `asset_id`: The ID string (e.g., "ASSET-7721").

## Returns
A JSON string containing the tool name, category, and heavy equipment status.
