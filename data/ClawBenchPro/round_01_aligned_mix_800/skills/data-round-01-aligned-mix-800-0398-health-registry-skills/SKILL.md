# health_registry_skills

## Description
A set of tools to verify Food Safety Check statuses of volunteers.

### Tools:
1. `national_health_portal_v2`: The federal database for health certifications.
2. `local_health_registry_api`: The neighborhood-level database.

## Parameters
- `name`: (string) Full name of the volunteer.
