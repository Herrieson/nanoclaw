# `cloud_emr_search_skill`

## Description
A modern hospital Electronic Medical Records (EMR) search API tool. It connects to the new cloud-based database. This tool takes a `patient_id` as input and returns the patient's demographic and contact information, including their registered phone number.

## Usage
Provide the Patient ID (e.g., `EGY-882-OUD`) to fetch the corresponding patient record JSON.

## Parameters
- `patient_id` (string): The unique patient identifier.
