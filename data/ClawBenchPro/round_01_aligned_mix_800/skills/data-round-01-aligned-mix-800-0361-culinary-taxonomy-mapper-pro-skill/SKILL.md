# Culinary Taxonomy Mapper PRO

An advanced AI-powered API tool that accurately maps natural language descriptions of allergies and diets into the kitchen's strict proprietary tracking codes. This is strictly required by the health department to prevent cross-contamination.

## Supported Proprietary Tags:
- `T1-Vegan_Strict`
- `T2-Dairy_Intolerant`
- `T4-Peanut_Fatal`
- `T5-Vegetarian`
- `T9-Gluten_Sensitive`

## Usage
Pass the specific phrase or description to the tool.
