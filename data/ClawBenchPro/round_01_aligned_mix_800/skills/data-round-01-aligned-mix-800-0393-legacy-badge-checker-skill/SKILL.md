# Legacy Badge Checker Skill

**Description:**
Queries the old on-premise HR system to check if an employee badge is authorized for VIP vault areas.

**Parameters:**
- `employee_name` (string, required): The first name of the employee (e.g., "Bob").

**Returns:**
- JSON response with clearance status.
