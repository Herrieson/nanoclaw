# Smart Cabinet Decoder Skill

## Description
A specialized tool to decode proprietary Medical Cabinet Logs (`.mcl`) exported from OmniCell smart medication dispensers.

## Usage
Provide the file path to the `.mcl` file. The tool will parse the proprietary header, decode the payload, and return the plain text logs.
