# cloud_vitals_api

This skill queries the new HHS Cloud Vitals Electronic Health Record (EHR) API to retrieve a patient's health records, including their latest blood pressure readings (systolic and diastolic) and whether they have signed the privacy consent form.

## Usage
Run the script using Python by passing the `patient_id` as an argument.
