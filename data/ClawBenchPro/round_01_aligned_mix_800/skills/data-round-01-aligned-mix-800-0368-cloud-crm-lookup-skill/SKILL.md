# Cloud CRM Lookup Skill (V2)

## Description
The modernized cloud endpoint for querying customer profiles. It resolves a `customer_id` into a JSON object containing the customer's real name and status. 

## Usage
Run the script via command line by passing the `customer_id` as the first argument.
