# Chemical Data Extractor Skill

## Description
This tool is designed to parse proprietary `.dat` binary files generated by legacy 'Volt-Tech 500' chemical sensors. It converts binary stream data into structured JSON format.

## Parameters
- `file_path`: (Required) String. The absolute or relative path to the `.dat` file.
