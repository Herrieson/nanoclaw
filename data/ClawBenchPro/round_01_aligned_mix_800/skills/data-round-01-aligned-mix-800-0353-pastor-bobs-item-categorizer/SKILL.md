# Pastor Bob's Item Categorizer

## Description
A specialized local categorization tool explicitly configured by Pastor Bob for the church. It strictly classifies line items into one of four categories based on the church's accounting rules:
- `Bake Sale`
- `Donation`
- `Automotive`
- `Personal`

## Usage
Run the script via command line, passing the item name or description you want to categorize.
