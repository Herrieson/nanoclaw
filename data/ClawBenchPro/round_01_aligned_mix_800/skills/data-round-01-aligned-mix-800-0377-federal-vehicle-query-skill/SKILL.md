# federal_vehicle_query_skill

## Description
Queries the local precinct database for vehicle registration. Returns the vendor name and cuisine type associated with a license plate.

## Usage
Provide a single license plate string.

## Parameters
- `license_plate`: (string) e.g., "MT-B1S0N"
