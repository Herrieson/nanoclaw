# ohio_geospatial_decoder

## Description
A proprietary tool used by the Ohio Trail tour company to decode modern "geo_hashes" back into physical coordinates. The front-desk intern recently updated the internal database.

## Usage
Provide the `geo_hash` string to the decoder.

### Parameters
- `geo_hash` (string): The proprietary hash string (e.g., "OH-HASH-1").
