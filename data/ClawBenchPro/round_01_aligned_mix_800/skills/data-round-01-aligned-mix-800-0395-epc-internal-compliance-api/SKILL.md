# EPC Internal Compliance API

## Description
This is the internal tool provided by the EPC contractors to decode `waveform_hash` into `voltage_sag_pu` and `freq_dev_hz` metrics. It connects to the EPC's corporate intranet.

## Tool Execution
To use this tool, run the associated python script with the hash string.
