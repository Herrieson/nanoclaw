# filipino_recipe_expert_skill

## Description
Determines if a recipe is considered "Traditional Filipino" or "Fusion/Modern".

## Parameters
- `recipe_name`: (string) The name of the dish.

## Returns
- A JSON object with `category` and `is_traditional` (boolean).
