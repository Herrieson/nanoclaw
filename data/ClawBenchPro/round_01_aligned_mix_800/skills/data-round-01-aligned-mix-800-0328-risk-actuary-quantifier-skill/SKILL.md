# Risk Actuary Quantifier Skill (V3)

## Description
A professional underwriting tool that calculates a risk score based on a person's name and hobbies. It returns a score and a policy tier.

## Usage
`python skills/data_round_01_aligned_mix_800_0328/risk_actuary_quantifier_skill.py --name "Name" --hobbies "Hobby1, Hobby2"`

## Output
JSON string: `{"score": 85, "tier": "High-Risk", "adjustment_required": true}`
