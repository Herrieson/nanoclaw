# e_sports_pdf_extractor_skill

## Description
A specialized tool for extracting raw JSON roster data from encrypted E-sports Federation PDF exports.

## Usage
`python skills/data_round_01_aligned_mix_800_0268/e_sports_pdf_extractor_skill.py --input <path_to_pdf>`

## Output
Returns a JSON string containing team names and player IDs.
