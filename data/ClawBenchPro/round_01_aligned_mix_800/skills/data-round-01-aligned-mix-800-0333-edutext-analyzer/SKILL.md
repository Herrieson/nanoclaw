# EduText Analyzer API

## Description
The official modern text analysis API used by the school district. It utilizes an advanced AI engine to evaluate student literature. It can determine the primary language of the text and detect if the text contains notes, draft markers (like "TODO"), or expresses high anxiety/nervousness.

## Usage
Pass the path to a readable text file (e.g., `.txt`) to analyze its contents.
