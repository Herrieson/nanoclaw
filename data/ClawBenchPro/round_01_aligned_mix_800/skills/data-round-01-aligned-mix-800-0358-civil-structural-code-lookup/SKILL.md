# civil_structural_code_lookup

Professional tool to query the Municipal Building & Safety Code (MBSC). Use this to verify if a site observation constitutes a legal violation.

## Parameters
- `query`: (required) A specific description of the hazard (e.g., "trench depth 6 feet", "scaffolding guardrail height 4ft").

## Returns
- A formal legal determination and the corresponding Code Section.
