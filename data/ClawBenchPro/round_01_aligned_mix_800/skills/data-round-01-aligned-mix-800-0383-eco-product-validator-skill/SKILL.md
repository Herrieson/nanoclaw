# Eco Product Validator Skill

This is an advanced, AI-powered eco-product validation tool that determines if a given item description qualifies as a "Reusable Water Bottle" acceptable for zero-waste initiatives. It handles brand names and generic descriptions accurately.

## Usage
Run the script with the item description as an argument. It returns a JSON string containing the validation result.
