# Art Catalog API (v2)

This is the newly deployed V2 version of the Art Supply Catalog API. It retrieves up-to-date pricing and item descriptions given an `ITEM_ID` (e.g., ART-SKB-01).

## Usage
Run the script using Python by passing the item ID as the argument.
