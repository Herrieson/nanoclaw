# `query_cloud_policy_api_skill`

## Description
This is a modern command-line tool to query the new Cloud Policy API. It retrieves the structured metadata, including `coverage_limit` (float) and `active_date` (YYYY-MM-DD), for a specific Insurance Policy ID.

## Usage
Execute the script by passing the exact policy ID as the first argument.
