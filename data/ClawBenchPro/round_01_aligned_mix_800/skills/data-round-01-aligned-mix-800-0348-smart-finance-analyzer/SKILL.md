# smart_finance_analyzer

A sophisticated tool that uses LLM-powered extraction to convert messy, unstructured expense strings into clean numerical data.

## Usage
- **Input**: `messy_string` (e.g., "approx 875.50 dollars")
- **Output**: A JSON object `{"amount": 875.50, "currency": "USD"}`
