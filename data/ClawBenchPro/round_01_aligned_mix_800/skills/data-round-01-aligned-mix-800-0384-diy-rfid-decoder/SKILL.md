# DIY RFID Decoder API

This tool decodes the raw hexadecimal/custom string payloads generated by the community pantry's DIY Raspberry Pi scanner into human-readable JSON data containing the volunteer's name and logged hours.

## Usage

You can invoke this tool via command line by passing the payload string.
