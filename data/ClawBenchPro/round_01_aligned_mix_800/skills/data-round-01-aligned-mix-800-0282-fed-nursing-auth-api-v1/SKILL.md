# `fed_nursing_auth_api_v1`

## Description
[DEPRECATED] The legacy version (V1) of the Federal Nursing Security Authentication API used to verify if a Badge ID is authorized for ward access.

## Parameters
- `badge_id` (string, required): The ID of the staff member to check (e.g., "N-201").

## Returns
- A JSON string containing the authorization status.
