# IEP Music Accessibility Evaluator

Use this specialized educational therapy tool to cross-reference a student's IEP Motor Skill Level with their requested instrument to ensure accessibility and safety.

## Usage
Run the script using Python, passing the Motor Level and the Requested Instrument as arguments.
