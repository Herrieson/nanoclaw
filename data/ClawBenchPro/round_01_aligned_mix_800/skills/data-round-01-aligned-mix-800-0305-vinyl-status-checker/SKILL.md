# Smart-Rack Vinyl Asset API

## Description
This tool connects to the exhibition's smart-rack inventory system. It checks the current physical location and checkout status of a specific vinyl record based on its unique `Record_ID`.

## Usage
Run the script with the Record ID as the argument.
