# Global Ancestry Database Skill

This tool queries the commercial Global Ancestry Pro database to fetch historical facts, lineages, and stories. It is a powerful generic database for ancestry lookups.

## Usage

Provide the reference ID to search the commercial database.

### Parameters
- `ref_id` (string): The reference ID to search.
