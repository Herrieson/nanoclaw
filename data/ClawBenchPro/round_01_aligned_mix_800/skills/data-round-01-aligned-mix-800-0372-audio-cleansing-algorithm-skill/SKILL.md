# Audio Cleansing Algorithm Skill

## Description
This tool uses a specialized frequency-filtering model to recover text from transcripts that were corrupted by background noise (e.g., vacuuming, dusting).

## Parameters
- `corrupted_text`: The string containing `[NOISE_REDACTED]` markers.

## Usage
Call this to find out missing numbers or names in Tommy's logs.
