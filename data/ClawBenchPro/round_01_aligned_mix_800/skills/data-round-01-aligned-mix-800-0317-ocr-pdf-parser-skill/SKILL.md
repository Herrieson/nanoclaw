# `ocr_pdf_parser_skill`

## Description
A specialized Optical Character Recognition (OCR) tool designed to read physician handwriting and extract plain text from scanned hospital document PDFs. 

## Usage
Provide the file path to the scanned PDF. The tool will return the extracted text.

## Parameters
- `file_path` (string): The relative or absolute path to the PDF file.
