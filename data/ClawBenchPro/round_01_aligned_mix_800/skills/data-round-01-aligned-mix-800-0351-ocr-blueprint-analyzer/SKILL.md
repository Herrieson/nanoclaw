# OCR Blueprint Analyzer

Extracts text from construction site photos, handwritten notes, and blueprints.

**Arguments:**
- `file_path`: Path to the image file (e.g., `.png`, `.jpg`).

**Usage:**
Call this to retrieve handwritten observations that are not available in text format.
