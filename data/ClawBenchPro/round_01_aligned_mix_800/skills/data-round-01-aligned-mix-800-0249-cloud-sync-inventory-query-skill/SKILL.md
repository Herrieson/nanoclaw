# Cloud Sync Inventory Query Skill

新版云端养老机构物资管理系统接口。这是旧系统的替代方案，提供高可用性的库存查询服务。

## 功能
通过物品名称（如 'Bleach', 'Soap'）动态查询系统的云端数据库，获取本周该物资的起始库存和当前库存。
