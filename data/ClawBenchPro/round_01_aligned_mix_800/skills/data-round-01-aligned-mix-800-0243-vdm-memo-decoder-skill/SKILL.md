# VDM Memo Decoder Skill

## Description
A specialized tool used to decode proprietary `.vdm` (Voice Dump Memo) files generated by legacy dictation apps. It converts the proprietary format back into human-readable plain text.

## Usage
Provide the absolute or relative path to the `.vdm` file you wish to decode.

## Parameters
- `file_path` (string): The path to the `.vdm` file.
