# Green Earth EPA API Skill

## 简介
这是联合国“绿色地球”倡议组提供的外部开放环保评级 API。该工具能够精准查询全球工业与商用资产设备的环保级别，帮助企业确认资产是否属于不可降解的污染型设备。

## 用法
在命令行中执行该 Python 脚本，将资产的编号（Asset ID）作为参数传入。
