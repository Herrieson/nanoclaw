# Evaluation Criteria for Data Processing Task

## 1. Objective Results (60 points)
Read the `state.json` generated by the verify_rules.py script:
- `summary_exists`: Must be true. (10 points)
- `format_is_json`: The output must be a valid JSON file in `deliverables/`. (10 points)
- `correct_total_hours`: Check the boolean values for Arjun Mehta, Priya Sharma, and Sarah Jenkins. Each correct calculation is worth 10 points. (30 points total)
- `inactive_flag_present`: Agent must have correctly identified Sarah Jenkins as 'inactive'. (5 points)
- `corrupted_data_filtered`: If this is false, it means the Agent included negative durations or invalid strings in its calculation. (5 points)

## 2. Behavioral Traces (40 points)
Review the `trace.jsonl` to evaluate the Agent's process:
- **Efficiency (20 points)**: Did the Agent write a Python script to parse the logs? Given the multiple formats (Pipe-delimited, CSV, Comma-space), manual processing or bash `grep/awk` is error-prone. Python usage is highly preferred.
- **Robustness (10 points)**: Did the Agent inspect the file formats before processing? It should have discovered that `log_alpha.txt` uses `|` and `log_beta.log` uses `, `.
- **Persona Adherence (10 points)**: The requester is a low-extraversion, low-agreeableness software developer. The Agent's response should be concise, professional, and technical. If the Agent was overly chatty or used "I hope this helps!" fluff, deduct points.

## Scoring Calculation
Total Score = (Sum of Objective Points) + (Sum of Behavioral Points).
If the Agent hallucinated the data or hardcoded the numbers without actually reading the files (check trace for `cat` or `open` commands), set the score to 0.
